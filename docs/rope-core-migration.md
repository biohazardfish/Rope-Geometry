# 繩結重建：可遷移性與實作報告

更新：2026-11-02。此文件區分已存在的能力、正在抽取的能力和未完成的驗收；共用模組不代表 Somerville 已完成。

## 本輪固定的基準

`loose-v2.json` 是完整鬆結，3,500 個中心線點，材料長 7.138936637394829 m。獨立檢查其 84,000 個管面三角形：零自交、零折疊、零穿柱。九項操作檢查通過，但這不是最終影片姿態驗收。

歷史流程改用 `videoTight` 時，材料長已變為 6.542174962462249 m，少了 0.5967616749325799 m。後續求解還有約 −3.145 mm 的殘差。兩個數字必須分別呈現，不能用重新設定種子的方式消除前者。

目前已描線段的總體 RMS 不能代表還原成功：摺彎超過一個繩徑、核心外有大量未解釋的可見繩路，而且交叉位置未驗證。

## 可遷移邊界

| 能力 | 可共用的內容 | 每個結仍須提供 |
|---|---|---|
| 幾何 | 穩健距離、旋轉最小化框架、解析曲線、掃掠管體 | 路由參數、環口與區段的配置 |
| 材料 | 固定 `s0`、段長、材料取樣與標記 | 材料端點、對折與操作涉及的材料區域 |
| 求解 | 段長投影、接觸搜尋、連續碰撞、步長回退 | 形狀目標、操作檢查點、允許移動的範圍 |
| 驗證 | 管面自交、局部折疊、柱碰撞、誤差計算 | 此結的穿環、越過、下穿與圈數要求 |
| 影像 | 相機擬合、連續中心線投影、疊圖 | 來源影格、遮擋、材料對應與交叉標註 |
| 展示 | 共用網格檢視、視角、區段上色、驗收狀態 | 模型與來源資料 |

## 最小介面契約

- `KnotRecipe` 描述材料路徑、操作、局部框架、來源、假設與幾何參數。觀察到的操作和為避免側彎所加的幾何轉角分開記錄。
- `RopeState` 保存不隨變形重設的參考材料座標 `s0`；`restLengths` 由相鄰 `s0` 差決定。目前幾何弧長另算。重新取樣仍以同一材料座標定位，不能把變短後的幾何弧長當成新的材料長。
- 結的語義區段與材料身份不是同一件事。繩滑過環口時，構成環口的材料位置可以改變；材料身份不能因此被重新編號或遺失。
- 共用引擎只接受顯式參數；不能內建 Somerville 的 cuff 名稱、X 軸方向、柱半徑或固定繩徑。
- 靜態管體有效、操作關係有效、材料守恆、運動安全和影片對齊分別報告。未驗證項不得併入總體 PASS。

## 避免重走遠路

1. 先交付完整可追蹤的鬆結，立即在正／背／側視檢查；不以局部核心或測試數量代替模型進展。
2. 生成器和驗證器共享角色與操作資料，但數值驗證獨立執行；不能靠生成器自己寫入 PASS。
3. 較緊的解析構型是求解目標；只有從原材料狀態安全移動到達，才算收緊成功。
4. 檢查所有未解釋的可見繩路。不能只挑選接近標註的點來取得低誤差。
5. 停滯時保存有效候選、具體殘差與失敗區段，再回到少量路由參數；不逐點修補。
6. 每個新抽象先在第二個簡單結使用。若仍須複製引擎或加入結名條件，表示抽取尚未完成。

## 遷移驗證範例

本輪使用單股單結（overhand knot），只驗證配方、材料狀態、共用管體、求解及檢視流程，不擴張成另一個影片還原專案。Somerville 的單柱、雙股與影像標註仍保留在專用適配層。
