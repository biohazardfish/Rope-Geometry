## 3. Answers to the inventory questions

### 3.1 Which files are essential? [V]

Essential means CI, tests or an HTML entry point break without the file:

- All 40 `src/` modules except `somerville-relax.js`, which only one test uses.
- The CI-wired scripts: `verify-geometry.js`, `audit-somerville.js`, `export-knoto-id.js` (spawned by `test/export-gate.test.js`), and `evaluate-somerville-dressed.js` (imported by two tests).
- Test-consumed data:
  - `data/B*.json`, `C.json`, the crossing topologies, `phase5-*`, `phase5-recovery/*`
  - both Somerville ledgers, `somerville-gauss-review.json`, `somerville-pose148.json`
  - `somerville-final/loose-v2.json`, `final.json`, `dressed-candidate.json`
  - `reports/phase5-recovery/baseline.json`
  - `reports/rope-edit/session1.json`
- `package*.json`, `vite.config.js`, the 5 HTML entries and `style.css`.

### 3.2 Which files are generated artifacts? [V]

Every file marked GEN above. The writer for each is listed in [DATA_FLOW.md](DATA_FLOW.md) §2.

Several GEN files are also test fixtures: `loose-v2.json`, `final.json`, `dressed-candidate.json`, `reports/rope-edit/session1.json` and `reports/phase5-recovery/baseline.json`. So "generated" does not mean "disposable".

### 3.3 Which files are obsolete? [V/I]

No file is safely obsolete in the sense of being unreferenced and unneeded. The following are **superseded** but still referenced:

- `data/somerville-final/loose.json` (v1 route), `continuation.json` and `final.json`. These are referenced by the viewer, tests and the evaluator's protected list [V].
- `pose-videoTight-history.json` and `reports/somerville-videoTight-history.json` have no producer [V].
- The Phase 5 / recovery data. It is preserved deliberately as a failed baseline and is asserted by tests [V].
- `reports/rope-reuse-*.json` and `reports/somerville-dressed-baseline.json` have no producer or consumer in code [V]. They are candidates for archiving.

### 3.4 Which files duplicate existing functionality? [V]

- `src/somerville-relax.js` is a re-export of `src/rope-relax.js`.
- `data/somerville-final/dressed-candidate.json` is byte-identical to `loose-v3.json`.
- `work/somerville/build-*.js` and `work/somerville/reuse/compact-route-prototype.js` are copies or forks of the Somerville builder [I].
- Algorithm-level duplicates (two distance kernels, five pair-sweep loops, four column-gap implementations, five viewer scaffolds) are covered in [ARCHITECTURE.md](ARCHITECTURE.md) §4.

### 3.5 Which files are actively referenced?

See the reference graph in [ARCHITECTURE.md](ARCHITECTURE.md) §2 [V]. These have **no code reference** [V]:

- `data/material-hemp-6mm.json`
- `reports/rope-reuse-*.json`
- `reports/somerville-dressed-baseline.json`
- `crossing-report.json`
- `scripts/author-phase4b.py` and `scripts/collect-phase4b.py` (they are producers, not consumed)
- Everything under `work/` except the SHA references in reports

### 3.6 Which directories are unnecessarily fragmented? [I]

- Reports are split between the repository root (`report.json`, `crossing-report.json`, `phase3/4/4b-report.json`) and `reports/`.
- Somerville outputs are spread across `data/somerville-final/`, `reports/somerville-*.json` (flat) and `work/somerville/`.
- `src/` is a flat directory of 40 files mixing core kernels, Somerville-specific code, the editor and five Three.js viewers. Responsibilities are only distinguishable by filename prefix.

### 3.7 Which experimental branches were abandoned? [V/I]

There are no abandoned *git* branches; only `main` and the feature branch exist [V]. Abandoned *lines of work* inside the tree:

- Phase 5 Candidate A (36 penetrations) and its recovery integration (74 penetrations) [V].
- The `videoTight` / PBD shortening pose solver (`final.json` FAIL) [V].
- The compact core route (`work/somerville/reuse/compact-route-prototype.js`, explicitly "do not adopt") [V].
- The v1 route. It is retained only because `operational-topology.js` documents that it contradicts the ledger [V].

### 3.8 Which files cannot be classified without further investigation? [U]

- `data/material-hemp-6mm.json`: is it a planned input for a future Cosserat backend, or abandoned metadata?
- `reports/rope-reuse-*.json` and `reports/somerville-dressed-baseline.json`: the producer is unknown.
- `crossing-report.json`: still meaningful after Phase 3, or superseded by `phase3-report.json`?
- `work/somerville/frames/*`: needed to reproduce `docs/somerville-dressed-core-ledger.md`?
- `reports/phase5/*.blend1`: probably accidental Blender backups [I].
