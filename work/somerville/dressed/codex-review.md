# Independent integration review (pending fixes)

1. `somerville-pose-fit.js` projected crossing excludes every segment endpoint (`t<=1e-8 || t>=1-1e-8`). A physical crossing that coincides with a sample vertex disappears after subdividing unchanged segments. Reproduced in `codex-crossing-review.json`: coarse PASS, geometrically identical subdivided FAIL. Include endpoint hits, deduplicate by material coordinates / projected location, and reject adjacent-material self contacts separately. Regression must cover subdivision.
2. Preserve and validate `uncertaintyPx` in crossing output; do not silently inflate the acceptance threshold with it. Missing/negative uncertainty must not become a reviewed measurement.
3. Scale calibration must verify actual rope diameter matches the calibration diameter; the constrained camera's range check should be distinguished from the diagnostic that the unconstrained optimum was outside the range. An admissible boundary solution with acceptable residuals is not automatically geometrically invalid solely because the unconstrained optimum was outside.
4. `unexplainedVisible` without options.materialArc self-occludes a densely sampled straight line because only immediate index adjacency is excluded. Independent reproduction: points t->[.1t,.1t,0], no annotations, columnRadius:0, camera ppm1000 origin[100,100], image300square, rope diameter6px. n=2 gives100px; n=11 gives100px; n=101 gives2px. Compute geometryArc internally for local visibility neighbourhoods when no materialArc supplied, validate provided arrays; add regression for this slanted-depth case (not only constant-depth line). Do not allow density to hide extra rope.
5. Dressed evaluation must enforce the engineering total 7.138936637394829 m independently of the seed own arc. A self-consistent 6 m candidate cannot pass materialLength merely because positions and s0 were both shortened. Report geometry total, reference total, and difference separately from segment strain. Static seed own s0 is permitted but is not evidence for expected total.
6. Numerical report must be deterministic for same input, independent of a previous report. `bestResidual` selection from prior report couples output to run history and does not retain the corresponding geometry/hash. Keep best-candidate tracking separate from deterministic evaluation.
7. Viewer reads candidate.somerville.acceptance, but evaluator currently only writes external reports/metadata. Integrate the evaluated report with matching candidate SHA (or write an evaluated copy with unambiguous geometry hash) so visible status and actual model agree. Do not trust stale report status for new geometry.
8. UI wording: use "整理後靜態候選" instead of literal "穿衣靜態候選". Core framing should persist when choosing front/rear/side; provide an explicit full-rope framing button rather than automatically zooming back to metre-long tails with every view switch.
