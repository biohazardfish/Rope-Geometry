# 互動走繩原型驗收與接手紀錄

2026-11-09

## 目前交付

桌面滑鼠原型可操作。A 可旋轉、平移及縮放視角，B 鎖鏡頭並拖動繩段。按住滑鼠時，繩子會逐子步移動。放開後完成守長、連續中心線碰撞及靜態管面檢查，再將 B 步驟入帳。

時間線分開保存 A 視角與 B 操作，支持保存、載入、撤銷、播放及重新求解後的 SHA-256 比對。每個 B 開始播放時恢復其鏡頭。載入會核對初始材料與固定場景，並重新求解所有步驟後才取代目前狀態。

本輪可繼續使用的成果包括固定點／逆質量求解、單步幾何閘門、版本化 session、獨立審核腳本與滑鼠編輯頁面。

## 開啟與重現

在專案根目錄執行以下命令。

```sh
npm run dev
```

開啟終端顯示的網址，路徑使用 /rope-edit.html。按 B，抓金色繩耳，沿金色箭頭往環口拖動。放開後回到 A，再轉動視角查看兩側。Shift 啟用 45° 吸附，Esc 取消尚未入帳的拖曳或結算。每次復原退回一個時間線事件。

載入同目錄 session1.json、session2.json 或 session3.json，可播放這次保存的實際接受路徑並重新求解核對。頁面只支援這個固定起始場景及匹配版本的工作階段。

獨立核算命令如下。

```sh
node scripts/audit-rope-edit.mjs reports/rope-edit/session1.json reports/rope-edit/session2.json reports/rope-edit/session3.json
npm test
npm run build
```

## 瀏覽器實測

Chrome 的真實滑鼠事件經管面選取進入拖曳流程，三次皆完成穿環。測試使用 1440 × 900 視窗，分別以 12、20、8 個 pointermove 事件走過同一條螢幕平面路徑。紀錄中的耗時包含按 B 至這一步完成，求解延遲另由相同接受序列重算量測。

| 輪次 | 耗時 | A／B 步數 | 誤選 | 阻擋子步 | 接受子步 | 單子步中位／p95 |
|---|---|---|---|---|---|---|
| 1 | 1.195 s | 1／1 | 0 | 0 | 56 | 9.2／9.8 ms |
| 2 | 1.092 s | 1／1 | 0 | 0 | 56 | 9.2／9.8 ms |
| 3 | 1.090 s | 1／1 | 0 | 0 | 56 | 9.2／10.0 ms |

三次存檔均能載入、撤銷、播放和重算比對。播放前先旋轉視角，再確認播放中恢復記錄的鏡頭。另以不同視角檢視穿環後的繩耳，畫面保存在 passed-rotated.png。

額外瀏覽器測試確認 A 操作只改變鏡頭，B 旋轉與滾輪被鎖定，固定段不能拖，拖曳中不能切換模式。Shift 顯示吸附，尚未放開時實際移動讀數達 14.8 mm。Esc、pointercancel 及放開後的 Esc 都還原整步。損壞存檔不會取代當前 session。

建置後的 production 頁面也能載入存檔、播放、重新求解，頁面錯誤為 0。

## 幾何獨立核算

三輪合計 168 個接受子步、1,118,040 個線段對運動區間。漏放穿越為 0，固定點漂移為 0。最大段長誤差小於 1.0e-11 m，最大總長誤差小於 4.6e-11 m。

每輪收尾管面均為自交 0、折疊 0、穿柱 0。指定繩耳的九個材料點都穿過孔徑內部並完整移到另一側，最後最靠近環面的點約越過 11.71 mm。從環外繞到另一側的負例會被穿環判定拒絕。

核算從保存點位重新列舉所有符合排除政策的線段對，重跑 CCD 及管體檢查，並使用 Node 的 SHA-256 核對結果。各個完整檔案的 SHA-256 見 review.json。

## 實作審查修正

- 固定直繩兩端時的冗餘長度約束曾產生 NaN，已修正並增加相容與不相容段長的回歸。
- 求解器保留既有呼叫行為，新增固定點及逆質量選項。柱體 CCD 依中心、軸與座標框架定位。
- 即時拖曳逐一處理已取樣的子步，子步間讓出事件迴圈，快速放開後仍可取消。每個實際保存子步都經過閘門。
- 穿環檢查涵蓋整個繩耳與穿越環面的歷史。
- 播放鎖定操作與對應鏡頭，撤銷恢復形狀及視角。載入會重新求解並核對中途接受點位。
- 移除了自動示範入口，以桌面 A／B 操作作為介面入口。
